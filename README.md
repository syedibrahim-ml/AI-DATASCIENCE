# Python Programming Journey - From Basics to Projects 🚀

Welcome to my repository! This project tracks my complete Python learning journey from day one. It contains all the concepts, logic-building exercises, data structures, and practical application systems I have designed and coded.

## 📚 What I Have Learned & Implemented

### 1. Python Basics & Control Flow
* **Variables & Accumulators:** Learned how to store values and track running sums using accumulator variables.
* **Conditional Logic:** Built validation logic using `if-elif-else` branches.
* **Looping Structures:** 
  * Utilized `for` loops to iterate over ranges, lists, and strings.
  * Utilized `while` loops for continuous execution and controlled exit conditions.
  * Implemented loop control statements like `break` and nested loops.

### 2. Lists & Multi-Dimensional Arrays (2D Lists)
* **List Manipulation:** Learned list methods including `.append()`, `.pop()`, `.insert()`, `.sort()`, `.reverse()`, and element replacement.
* **List Slicing:** Mastered extraction techniques using `list[start:stop:step]` (including reversing sequences with `[::-1]`).
* **Multi-Dimensional Lists:** Processed matrix-like data structures using nested loops to access elements inside 2D grids.

### 3. Advanced String Manipulation
* **Searching & Filtering:** Utilized `.find()`, `.rfind()`, `.partition()`, and substring membership testing (`in`).
* **Formatting:** Formatted complex outputs clean and readable using `f-strings`, padding, alignment, and decimal precision configurations (`:.1f`).
* **Validation Methods:** Applied `.isalpha()`, `.isdigit()`, `.isalnum()`, `.startswith()`, and `.endswith()` to check and clean data.
* **Text Cleaning:** Learned to modify strings using `.lower()`, `.upper()`, `.title()`, `.strip()`, and `.replace()`.
